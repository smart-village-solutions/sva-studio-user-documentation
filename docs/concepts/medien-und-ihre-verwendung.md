# Medien und ihre Verwendung

**Medien** sind Bilder und Dateien, die Sie in Inhalten verwenden können. In der [Medienbibliothek](/pages/host.media.list) suchen oder laden Sie Dateien hoch. In den Angaben zu einer Datei können Sie unter anderem Titel und Alternativtext prüfen. Ein Alternativtext beschreibt den Inhalt eines Bildes für Menschen, die es nicht sehen können.

Eine Datei kann in mehreren Inhalten vorkommen, etwa als Vorschaubild einer Nachricht und als Download an anderer Stelle. Die [Medienverwendung](/pages/media.usage) zeigt die Verknüpfungen. Möchten Sie eine Verknüpfung entfernen, öffnen Sie den betreffenden **Inhalt** und ändern ihn dort. Prüfen Sie die Verwendung erneut, bevor Sie eine Datei löschen.

Beim Hochladen kann die Datei als **öffentlich** oder **geschützt** eingestuft werden. Öffentlich bedeutet, dass sie über ihre Adresse abrufbar sein kann. Verwenden Sie für persönliche oder vertrauliche Dateien nur eine geeignete geschützte Ablage und klären Sie die Freigabe vor der Veröffentlichung.
