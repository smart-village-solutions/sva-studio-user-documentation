# Instanzen, Module und Berechtigungen

Eine **Instanz** ist ein abgegrenzter Arbeitsbereich im Studio. Dort werden die verfügbaren
Fachbereiche und die zugehörigen Konten verwaltet. Achten Sie zuerst darauf, in welcher
Instanz Sie gerade arbeiten: Einstellungen und Inhalte können sich zwischen Instanzen unterscheiden.

Ein **Modul** schaltet einen Fachbereich frei. Das allein erlaubt noch keine Änderung.
**Berechtigungen** bestimmen, welche Aktionen Sie dort ausführen dürfen. Rollen bündeln solche
Berechtigungen; Gruppen bündeln passende Rollen für mehrere Personen. Deshalb werden neue
Konten üblicherweise zuerst Gruppen zugeordnet. Auch Ihre Organisationszuordnung kann
beeinflussen, welche Daten Sie bearbeiten dürfen.

Fehlt eine erwartete Aktion, prüfen Sie zuerst Instanz, Modul und Ihre Berechtigungen.
Administratoren können die [Benutzerdetails](/pages/admin.users.detail),
[Gruppen](/pages/admin.groups.list) und [Rollen](/pages/admin.roles.list) dazu einsehen.
Die [Modulübersicht](/pages/modules.overview) erklärt die Zuordnung eines Fachbereichs.

Für die praktische Kontoverwaltung lesen Sie [Benutzer und Zugriff verwalten](/guides/benutzer-und-zugriff-verwalten).
