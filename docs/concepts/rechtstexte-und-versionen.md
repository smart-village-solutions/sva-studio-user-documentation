# Rechtstexte und Versionen

**Rechtstexte** sind rechtliche Hinweise oder Einwilligungstexte, die Personen im Studio angezeigt werden. Eine **Version** ist eine bestimmte Fassung eines Textes. Prüfen Sie bei jeder Fassung Name, Versionsnummer, Sprache und Zielgruppe zusammen: Gleichnamige Texte können sich darin unterscheiden.

Eine Fassung kann als **Entwurf**, **Gültig** oder **Archiviert** gekennzeichnet sein. Für eine gültige Fassung ist ein Veröffentlichungszeitpunkt erforderlich. Über Rollen und Gruppen wird festgelegt, für wen der Text gilt. In der [Rechtstextliste](/pages/admin.legal-texts.list) sehen berechtigte Personen die Fassungen und können eine davon öffnen.

Beispiel: Ein Datenschutzhinweis wurde inhaltlich geändert. Stimmen Sie die neue Fassung fachlich und rechtlich ab, bevor Sie sie als gültig bereitstellen. Prüfen Sie, ob eine neue Versionsnummer nötig ist, damit frühere Zustimmungen weiterhin der richtigen Fassung zugeordnet bleiben. Eine bereits gültige Fassung einfach umzuschreiben kann die Bedeutung früherer Zustimmungen verändern.
