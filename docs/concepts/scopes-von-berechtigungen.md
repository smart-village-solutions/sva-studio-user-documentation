# Scopes von Berechtigungen

Ein **Scope** ist der *Geltungsbereich* eines Rechts. Das Recht beantwortet die Frage „Was darf ich tun?“; der Scope ergänzt „Für welche Inhalte?“. Nicht jedes Recht bietet eine Auswahl des Geltungsbereichs. In der **Rollenverwaltung** sehen Sie die verfügbaren Scopes nur bei den dafür vorgesehenen Rechten.

Für Inhaltsrechte können diese Bezeichnungen erscheinen:

| Scope im Studio | Bedeutung |
| --- | --- |
| **Nur eigene Inhalte** | Das Recht gilt für Inhalte, die Ihrem persönlichen Account zugeordnet sind. |
| **Eigene Inhalte und Inhalte der aktiven Organisation** | Das Recht gilt zusätzlich für Inhalte der Organisation, in der Sie gerade arbeiten. |
| **Alle Inhalte dieser Instanz** | Das Recht gilt für alle Inhalte im Studio-Arbeitsbereich. |

Der Scope erweitert ein Recht nicht um andere Aktionen. „Inhalte lesen“ mit einem weiten Scope erlaubt zum Beispiel noch kein Bearbeiten. Auch ein Organisations-Scope setzt voraus, dass eine aktive Organisation und die nötige Zuordnung vorliegen.

Wenn mehrere Rollen oder Gruppen dasselbe Recht vergeben, kann der weiter reichende gültige Scope wirksam werden. In den [Benutzerdetails](/pages/admin.users.detail) können Personen mit Verwaltungsrechten unter **Berechtigungen** prüfen, welche Zuweisung gilt. Sie selbst können vor einer Änderung die **Aktive Organisation** im Kontomenü kontrollieren.

Siehe auch [Rechte, Rollen und Gruppen](/concepts/module-und-berechtigungen) und [Accounts und Organisationen](/concepts/accounts-und-organisationen).
