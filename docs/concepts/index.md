# Konzepte

Mit dem SVA Studio pflegen Teams Inhalte und Medien für ihre digitalen Angebote. Berechtigte
Personen verwalten außerdem Arbeitsbereiche und Zugänge. Welche Fachbereiche verfügbar sind,
hängt von den freigeschalteten Modulen ab. Die folgenden Seiten erklären diese Zusammenhänge
unabhängig von einer einzelnen Studio-Ansicht:

- [Module und Berechtigungen](/concepts/module-und-berechtigungen)
- [Inhalte und Veröffentlichung](/concepts/inhalte-und-veroeffentlichung)

Wenn Sie eine konkrete Aufgabe erledigen möchten, beginnen Sie bei den [Anleitungen](/guides/).
Die [Seitenhilfe](/pages/home.overview) beschreibt Bedienelemente der jeweiligen Ansicht.
