# Monitoring

Hier finden berechtigte Personen laufende und frühere Hintergrundaufträge. Ein Hintergrundauftrag ist eine Aufgabe, die das Studio selbstständig verarbeitet.

## Aufträge öffnen

Wählen Sie **Zu den Monitoring Jobs**, um Status und Fortschritt zu sehen. Öffnen Sie einen Eintrag für Einzelheiten. Bei einer Fehlermeldung notieren Sie die Job-ID und wenden Sie sich an die zuständige Administration.

## Berechtigungsprüfung messen

Für Administratorinnen und Administratoren gibt es außerdem **Authorize Performance**, eine Messfunktion für Berechtigungsanfragen. Geben Sie **Action-ID** und **Resource-Typ** nur ein, wenn Sie wissen, welche Prüfung durchgeführt werden soll. Die angezeigten Zeiten beschreiben die Verarbeitung auf dem Server; sie sagen nichts über die Ladezeit der gesamten Seite aus. Verwenden Sie in Beispielen keine personenbezogenen Kennungen.
