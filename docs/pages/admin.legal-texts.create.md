# Rechtstext anlegen

## Wofür ist diese Seite gedacht?

Hier erstellen Sie eine neue sprach- und versionsbezogene Rechtstextfassung.

## Voraussetzungen

- Sie besitzen das Recht, Rechtstexte anzulegen.
- Version, Sprache, Zielgruppen und Veröffentlichungsstatus sind rechtlich abgestimmt.

## Das können Sie hier tun

- Name, Version und Sprache festlegen.
- Status und Veröffentlichungszeitpunkt erfassen.
- Zielrollen und Zielgruppen zuordnen.
- Den HTML-Inhalt mit dem bereitgestellten Editor pflegen.

## Wichtige Hinweise

- Eine gültige Fassung benötigt ein Veröffentlichungsdatum in der Fachzeitzone Europe/Berlin.
- Eine bereits vorhandene Kombination aus Rechtstext und Version erzeugt einen Konflikt.
