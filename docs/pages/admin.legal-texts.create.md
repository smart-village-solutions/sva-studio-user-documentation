# Rechtstext anlegen

## Wofür ist diese Seite gedacht?

Hier erstellen Sie eine neue Fassung eines rechtlichen Textes für eine bestimmte Sprache und Zielgruppe.

## Voraussetzungen

- Sie besitzen das Recht, Rechtstexte anzulegen.
- Inhalt, Version, Sprache und Zielgruppe wurden fachlich und rechtlich freigegeben.

## So gehen Sie vor

1. Öffnen Sie **Rechtstexte** und wählen Sie **Rechtstext anlegen**.
2. Geben Sie Namen, Version und Sprache ein. Wählen Sie den Status **Entwurf**, **Gültig** oder **Archiv**.
3. Bei **Gültig** tragen Sie einen Veröffentlichungszeitpunkt ein. Legen Sie fest, für welche Rollen und Gruppen der Text gilt.
4. Erfassen Sie den Inhalt im Editor. Prüfen Sie ihn sorgfältig und wählen Sie **Rechtstext anlegen**.

## Wichtige Hinweise

- Veröffentlichen Sie nur fachlich und rechtlich geprüfte Fassungen. Für eine gültige Fassung ist ein Veröffentlichungszeitpunkt erforderlich.
- Wenn Studio eine bereits vorhandene Version meldet, prüfen Sie zuerst die bestehende Fassung.
