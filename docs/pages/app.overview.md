# App-Konfiguration

Der Navigationspunkt **App** führt derzeit zu einer vorbereiteten Seite. Dort können Sie noch keine App-Einstellungen ändern.

Wenn Sie etwas an einer Fachfunktion ändern möchten, öffnen Sie den passenden Bereich in der Navigation. Welche Bereiche sichtbar sind, hängt von den freigeschalteten Modulen und Ihren Berechtigungen ab. Fehlt ein erwarteter Bereich, wenden Sie sich an Ihre Administration.
