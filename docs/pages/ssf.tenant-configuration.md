# SSF konfigurieren

Hier sehen Sie die Einstellungen und Inhalte für Smart Speech Flow (SSF). Mit entsprechender Berechtigung können Sie Texte und weitere Angaben anpassen.

## Inhalte anpassen

1. Öffnen Sie **SSF-Konfiguration**.
2. Prüfen Sie im Reiter **Inhalte V2** die übernommenen Vorgaben für Logo, Mitarbeitendentexte, Gastsprachen, Rückmeldung und Speicherung von Gesprächsinhalten.
3. Ändern Sie die gewünschten Angaben. Ein Hinweis am Feld zeigt, ob ein Wert aus der Vorlage stammt oder hier angepasst wurde. Mit **Systemstandard verwenden** stellen Sie die Vorgabe für dieses Feld wieder her.
4. Wählen Sie **Änderungen speichern** und prüfen Sie die Bestätigung. Bei einer Fehlermeldung kontrollieren Sie die markierten Angaben.

Wenn keine Vorlage eingerichtet ist, zeigt die Seite einen entsprechenden Hinweis. Wenden Sie sich dann an Ihre Administration. Ohne Bearbeitungsrecht können Sie die Angaben ansehen, aber nicht speichern.

**Verwerfen** stellt den zuletzt gespeicherten Stand wieder her. Der Reiter **Bisherige Konfiguration** enthält ältere Einstellungen; die hier beschriebenen Inhalte stehen unter **Inhalte V2**.
