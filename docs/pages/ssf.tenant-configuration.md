# SSF konfigurieren

Hier sehen Sie die Inhalte für Smart Speech Flow (SSF), die in Ihrem Studio bearbeitet werden können. Mit entsprechender Berechtigung können Sie Texte und weitere Angaben anpassen.

## Inhalte anpassen

1. Öffnen Sie **SSF-Konfiguration**.
2. Prüfen Sie im Reiter **Inhalte V2** Logo, Mitarbeitendentexte, Gastsprachen, Rückmeldung und Speicherung von Gesprächsinhalten. Bei einem Feld sehen Sie, ob der angezeigte Wert übernommen oder hier angepasst wurde.
3. Ändern Sie nur die Angaben, für die Sie zuständig sind. Mit **Systemstandard verwenden** setzen Sie die Änderung am jeweiligen Feld zurück. Der übernommene Wert wird wieder angezeigt.
4. Prüfen Sie bei der Speicherung von Gesprächsinhalten die angezeigte Einstellung, die Aufbewahrungsdauer und die erläuternden Texte gemeinsam. Wenn Sie eine Gastsprache deaktivieren, prüfen Sie vor dem Speichern die übrigen Sprachfassungen.
5. Wählen Sie **Änderungen speichern** und prüfen Sie die Bestätigung. Bei einer Fehlermeldung kontrollieren Sie die markierten Angaben.

Wenn keine Vorlage eingerichtet ist, zeigt die Seite einen entsprechenden Hinweis. Wenden Sie sich dann an Ihre Administration. Ohne Bearbeitungsrecht können Sie die Angaben ansehen, aber nicht speichern.

**Verwerfen** stellt den zuletzt gespeicherten Stand wieder her. Die hier beschriebenen Inhalte stehen unter **Inhalte V2**.
