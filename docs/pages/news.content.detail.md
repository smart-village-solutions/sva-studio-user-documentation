# Nachricht bearbeiten

Hier ändern Sie eine vorhandene Nachricht und ihren Veröffentlichungsstatus.

## So gehen Sie vor

1. Prüfen Sie Überschrift, Einleitung, Haupttext, Quelle und Bilder.
2. Kontrollieren Sie, ob die Nachricht Entwurf, geplant oder veröffentlicht ist. Passen Sie den Termin bei Bedarf an.
3. Vor einer Push-Benachrichtigung: Prüfen Sie die angezeigte Empfängerauswahl. Ein Push kann für eine Nachricht nur einmal gesendet werden.
4. Speichern Sie und beachten Sie die Rückmeldung. Die Historie zeigt Änderungen, die im Studio vorgenommen wurden.

Nach einem Push können Sie die frühere Empfängerauswahl ansehen, aber nicht erneut versenden. Auch wenn der Push nur an ausgewählte Abholorte ging, bleibt die veröffentlichte Nachricht grundsätzlich öffentlich sichtbar.

Falls ein Medienfehler gemeldet wird, prüfen Sie die Bildverknüpfungen; der Nachrichtentext kann bereits gespeichert sein.
