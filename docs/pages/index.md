# Seitenhilfe

Die Seitenhilfe erklärt, was Sie auf **einer bestimmten Studio-Seite** sehen und dort tun
können. Im Studio öffnet das Fragezeichen neben dem Seitentitel direkt die passende Erklärung.
Auf dieser Website wählen Sie die gesuchte Seite in der Seitenleiste aus.

## Häufige Einstiege

- [Studio-Übersicht](/pages/home.overview): auf der Startseite orientieren.
- [Inhalte verwalten](/pages/content.list): Einträge suchen und öffnen.
- [Medien verwalten](/pages/host.media.list): Bilder und Dateien finden.
- [Benutzer verwalten](/pages/admin.users.list): Konten und ihren Status prüfen.

Wenn Sie eine Aufgabe **über mehrere Seiten hinweg** erledigen möchten, beginnen Sie bei den
[Anleitungen](/guides/). Dort finden Sie zum Beispiel den gesamten Ablauf vom Entwurf bis zur
Veröffentlichung einer Nachricht.
