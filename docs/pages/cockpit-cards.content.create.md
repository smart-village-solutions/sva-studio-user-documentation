# Kachel anlegen

Eine Cockpit-Kachel stellt einen kurzen Inhalt mit Bild und optionalem Link dar. Nutzen Sie sie, um auf ein Angebot oder eine weiterführende Seite aufmerksam zu machen.

## So gehen Sie vor

1. Geben Sie eine verständliche Überschrift und einen kurzen Text ein.
2. Wählen Sie Sprache und Kategorie. Falls mehrere Kacheln erscheinen, legen Sie über das Sortiergewicht ihre Reihenfolge fest.
3. Fügen Sie bei Bedarf Bilder hinzu und prüfen Sie deren Reihenfolge.
4. Hinterlegen Sie einen Link und einen aussagekräftigen Linktext, wenn die Kachel zu einer anderen Seite führen soll.
5. Prüfen Sie Sichtbarkeit und Veröffentlichungszeitpunkt. Speichern Sie danach die Kachel.

Für Links und Bildadressen wird eine sichere `https://`-Adresse erwartet. Der Kacheltext ist Klartext; HTML-Code gehört nicht hinein. Das Sortiergewicht muss eine ganze Zahl sein.
