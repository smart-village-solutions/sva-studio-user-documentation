# Konto-Einladung anpassen

## Wofür ist diese Seite gedacht?

Hier passen Sie die Einladungs-E-Mail für die aktuelle Instanz an. Neue Personen sehen diesen Text, wenn Sie ihnen eine E-Mail zur Einrichtung ihres Passworts senden.

## Voraussetzungen

- Sie besitzen das Recht, die Einladungsvorlage dieser Instanz zu ändern.
- Der Text ist fachlich abgestimmt.

## So gehen Sie vor

1. Öffnen Sie **Account-Einladung anpassen** und prüfen Sie, welche Vorlage derzeit verwendet wird.
2. Wählen Sie **Account-Einladung anpassen**. Ändern Sie Betreff, Nachricht und die Beschriftungen der Links.
3. Prüfen Sie die Vorschau mit dem Namen und der Startseite Ihrer Instanz.
4. Speichern Sie. Wenn Sie wieder die installationsweite Vorlage verwenden möchten, wählen Sie **Zurücksetzen** und bestätigen Sie.

## Wichtige Hinweise

- Lassen Sie die benötigten Platzhalter im Nachrichtentext stehen. Der Passwortlink muss genau einmal vorkommen; beim Versand wird er durch den persönlichen Einrichtungslink ersetzt.
- Die Vorschau versendet keine Nachricht. Wenn Studio einen Änderungskonflikt meldet, prüfen Sie zuerst den neu geladenen Stand.
