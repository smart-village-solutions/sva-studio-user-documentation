# Allgemeinen Inhalt bearbeiten

Hier ändern Sie einen vorhandenen allgemeinen Inhalt mit seinen Texten und weiteren Angaben.

## So gehen Sie vor

1. Prüfen Sie Überschrift, Sichtbarkeit und die vorhandenen Textabschnitte.
2. Aktualisieren Sie nur die Angaben, die für diesen Inhalt genutzt werden, zum Beispiel Kontakt, Termine oder Öffnungszeiten.
3. Prüfen Sie Bilder und ihre Reihenfolge. Fehlt bei einem Bild die Vorschau, kontrollieren Sie die Verknüpfung zur Mediathek.
4. Speichern Sie und beachten Sie die Rückmeldung. Die Historie zeigt Änderungen aus dem Studio.

Manuell eingetragene Bildadressen können später ungültig werden. Wenn Bilder oder andere Angaben über Zusatzdaten im JSON-Format gesteuert werden, ändern Sie diese nur mit Kenntnis der vereinbarten Struktur.
