# Instanz bearbeiten

## Wofür ist diese Seite gedacht?

Hier sehen Sie den Zustand einer Instanz und die nächsten Schritte für ihre Einrichtung oder Verwaltung.

## Voraussetzungen

- Die Instanz ist vorhanden.
- Sie besitzen die Rechte für die jeweils aufgerufene Betriebs- oder Konfigurationsaktion.

## So gehen Sie vor

1. Prüfen Sie im Bereich **Betrieb** den aktuellen Status und die angezeigte nächste Aufgabe.
2. Öffnen Sie **Doctor**, wenn Studio einen Fehler oder eine Warnung zeigt. Lesen Sie den Befund und den vorgeschlagenen nächsten Schritt.
3. Unter **Einstellungen** prüfen und ändern Sie Angaben wie Name, Adresse oder Anmeldung. Speichern Sie nur abgestimmte Änderungen.
4. Prüfen Sie bei Bedarf Module und Verlauf. Nach einer Aktion kontrollieren Sie, ob sich der Status wie erwartet geändert hat.

## Wichtige Hinweise

- Gespeicherte Zugangsdaten werden nicht im Klartext angezeigt.
- Führen Sie Reparaturaktionen nur aus, wenn der angezeigte Befund sie verlangt. Bei Unsicherheit geben Sie den Befund an die technische Administration weiter.
- Diese Seite verwaltet eine Instanz; neue Studio-Software wird darüber nicht veröffentlicht.
