# Benutzer anlegen

## Wofür ist diese Seite gedacht?

Hier erstellen Sie ein Konto und legen fest, mit welchen Gruppen die Person beginnen soll.

## Voraussetzungen

- Sie besitzen das Recht, Benutzer anzulegen.
- Sie kennen die E-Mail-Adresse sowie Vor- und Nachnamen der Person.

## So gehen Sie vor

1. Öffnen Sie **Benutzer** und wählen Sie **Benutzer anlegen**.
2. Tragen Sie E-Mail-Adresse, Vorname und Nachname ein.
3. Wählen Sie die passenden Gruppen. Öffnen Sie **Erweiterte Rollen** nur, wenn eine direkte Rollenzuweisung nötig ist.
4. Entscheiden Sie, ob Studio eine E-Mail zur Einrichtung des Passworts senden soll. Prüfen Sie das Einladungsziel und wählen Sie **Anlegen**.
5. Kontrollieren Sie auf der folgenden Detailseite, ob Konto und Einladung erfolgreich erstellt wurden.

## Wichtige Hinweise

- Vergeben Sie nur die Gruppen und Rollen, die für die Aufgabe benötigt werden.
- Falls nur der E-Mail-Versand scheitert, ist das Konto möglicherweise bereits angelegt. Prüfen Sie die Detailseite, bevor Sie es erneut erstellen.
- **Technisches Konto** ist nur für Dienstkonten gedacht, nicht für Personen.
