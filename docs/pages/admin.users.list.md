# Benutzerverwaltung

## Wofür ist diese Seite gedacht?

Hier finden Sie die Benutzerkonten und sehen, ob eine Person das Studio nutzen kann.

## Voraussetzungen

- Sie besitzen Leserechte für Benutzer.

## So gehen Sie vor

1. Öffnen Sie **Benutzer** → **Accounts** und suchen Sie nach Name oder E-Mail-Adresse. Nutzen Sie den Statusfilter, wenn Sie nur aktive oder inaktive Konten sehen möchten.
2. Aktivieren Sie bei Bedarf **Auch technische Accounts anzeigen**. Diese Konten dienen Diensten und gehören keiner Person.
3. Öffnen Sie ein Konto, um Gruppen, Rollen und Organisationen zu prüfen.
4. Nutzen Sie **Nutzer anlegen** für ein neues Konto. Für Aktivierung, Deaktivierung und Sammelaktionen prüfen Sie zuerst die ausgewählten Konten und bestätigen dann die Aktion.

## Wichtige Hinweise

- Das eigene Konto und der letzte aktive System-Administrator sind vor bestimmten Deaktivierungen geschützt.
- Sammelaktionen sind auf höchstens 50 ausgewählte Konten begrenzt.
