# Benutzer verwalten

## Wofür ist diese Seite gedacht?

Die Benutzerliste bündelt Kontostatus, Keycloak-Zuordnung und Verwaltungsaktionen der aktuellen Instanz.

## Voraussetzungen

- Eine Instanz ist aktiv.
- Sie besitzen Leserechte für Benutzer.

## Das können Sie hier tun

- Nach Name oder E-Mail suchen und nach Status filtern.
- Technische Accounts bei Bedarf einblenden.
- Konten aktivieren, deaktivieren oder zur Bearbeitung öffnen.
- Benutzer mit Keycloak synchronisieren oder Mainserver-Daten aktualisieren.

## Wichtige Hinweise

- Das eigene Konto und der letzte aktive System-Administrator sind vor bestimmten Deaktivierungen geschützt.
- Bulk-Aktionen sind auf höchstens 50 ausgewählte Konten begrenzt.
