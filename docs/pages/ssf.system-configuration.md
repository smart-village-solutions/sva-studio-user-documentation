# SSF-Standards einrichten

Hier legen berechtigte Personen die gemeinsamen Vorgaben für Smart Speech Flow (SSF) fest. Diese Texte und Einstellungen bilden die Grundlage für die SSF-Konfiguration einzelner Instanzen.

## Inhalte für Start und Anmeldung

1. Öffnen Sie **SSF-Standards** und den Reiter **Inhalte V2**.
2. Wählen Sie **Installation**. Tragen Sie bei Bedarf Logo und Symbol samt beschreibendem Alternativtext ein.
3. Hinterlegen Sie die Links zu Impressum und Datenschutzerklärung. Prüfen Sie auch die Angaben zur Barrierefreiheit.
4. Wählen Sie die Sprache und bearbeiten Sie die Texte für Startseite, Anmeldung und Rückmeldung.
5. Wählen Sie **Änderungen speichern**. Die Erfolgsmeldung bestätigt die Übernahme dieses Abschnitts.

## Vorlage für Gespräche

1. Wechseln Sie zu **Vorlage für Mandanten**. Diese Vorgaben können in der Konfiguration einer Instanz übernommen oder dort gezielt angepasst werden.
2. Prüfen Sie Texte für Mitarbeitende und Gäste, angebotene Sprachen, Rückmeldung sowie die Einstellung zur Speicherung von Gesprächsinhalten.
3. Speichern Sie den Abschnitt separat. Prüfen Sie Fehlermeldungen an den Feldern, falls das Speichern nicht gelingt.

**Verwerfen** setzt den gerade bearbeiteten Abschnitt auf den zuletzt gespeicherten Stand zurück. Der Reiter **Bisherige Konfiguration** enthält ältere Einstellungen; verwenden Sie für die hier beschriebenen Inhalte den Reiter **Inhalte V2**. Prüfen Sie vor dem Speichern insbesondere Pflichtfelder und HTTPS-Adressen.
