# Kategorien

Kategorien ordnen Inhalte in einer Baumstruktur. Eine Unterkategorie gehört zu einer übergeordneten Kategorie. Welche Schaltflächen Sie sehen, hängt von Ihren Rechten und der verfügbaren Anbindung ab.

## Kategorien finden

1. Öffnen Sie **Kategorien** in der Navigation.
2. Prüfen Sie Name, übergeordnete Kategorie, Position und Status in der Liste.
3. Wenn die Liste nicht lädt, wählen Sie **Erneut laden**. Bleibt der Fehler bestehen, melden Sie ihn Ihrer Administration.

## Kategorie anlegen oder ändern

1. Wählen Sie **Kategorie anlegen** oder öffnen Sie eine vorhandene Kategorie zum Bearbeiten. Für eine Unterkategorie wählen Sie bei der übergeordneten Kategorie **Neue Unterkategorie**.
2. Geben Sie mindestens einen Namen ein. Wählen Sie bei Bedarf eine übergeordnete Kategorie und eine Position für die Reihenfolge.
3. Ergänzen Sie nur benötigte Angaben wie **Icon** (Symbol), **Benachrichtigungs-E-Mail** und zugeordnete **Datentypen**. Mit **Aktiv** legen Sie fest, ob die Kategorie verwendet werden soll.
4. Wählen Sie **Speichern** und prüfen Sie die Erfolgsmeldung sowie den Eintrag in der Liste.

## Löschen und Status ändern

Wenn Sie den Aktivstatus einer Kategorie mit Unterkategorien ändern, kann das Studio eine Bestätigung für die betroffenen Unterkategorien verlangen. Lesen Sie die angezeigte Anzahl, bevor Sie fortfahren.

Beim Löschen zeigt das Studio einen Bestätigungsdialog. Wird die Kategorie noch verwendet, bleibt sie erhalten und der Dialog zeigt die Verwendungen nach Art und Anzahl an. Prüfen Sie diese Zuordnungen, statt den Löschversuch zu wiederholen. Falls eine Aktion fehlt oder deaktiviert ist, kann Ihre Berechtigung oder die Anbindung sie nicht erlauben.
