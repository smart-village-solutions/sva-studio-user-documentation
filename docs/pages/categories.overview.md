# Kategorien

Kategorien ordnen Inhalte in einer Baumstruktur. Eine Unterkategorie gehört zu einer übergeordneten Kategorie. Welche Schaltflächen Sie sehen, hängt von Ihren Rechten und der verfügbaren Anbindung ab.

## Kategorien finden

1. Öffnen Sie **Kategorien** in der Navigation.
2. Prüfen Sie Name, übergeordnete Kategorie, Position und Status in der Liste.
3. Wenn die Liste nicht lädt, wählen Sie **Erneut laden**. Bleibt der Fehler bestehen, melden Sie ihn Ihrer Administration.

## Kategorie anlegen oder ändern

1. Wählen Sie **Kategorie anlegen** oder öffnen Sie eine vorhandene Kategorie zum Bearbeiten. Für eine Unterkategorie wählen Sie die entsprechende Aktion bei ihrer übergeordneten Kategorie.
2. Geben Sie mindestens einen Namen ein. Wählen Sie bei Bedarf eine übergeordnete Kategorie und eine Position für die Reihenfolge.
3. Ergänzen Sie nur benötigte Angaben wie Symbol, E-Mail-Adresse und zugeordnete Inhaltstypen. Mit **Aktiv** legen Sie fest, ob die Kategorie verwendet werden soll.
4. Wählen Sie **Speichern** und prüfen Sie die Erfolgsmeldung sowie den Eintrag in der Liste.

## Löschen und Status ändern

Eine Statusänderung kann eine Bestätigung verlangen. Prüfen Sie diese vor dem Fortfahren. Beim Löschen zeigt das Studio einen Bestätigungsdialog; kontrollieren Sie, ob die richtige Kategorie ausgewählt ist. Falls eine Aktion fehlt, kann Ihre Berechtigung oder die Anbindung sie nicht erlauben.
