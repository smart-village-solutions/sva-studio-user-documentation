# Datei vorbereiten

Diese Seite bereitet einen Datei-Upload vor. Wenn Sie einfach eine Datei auswählen möchten, verwenden Sie die [Medienbibliothek](/pages/host.media.list).

## So gehen Sie vor

1. Prüfen Sie Dateityp und Dateigröße.
2. Wählen Sie, ob die Datei **öffentlich** oder **geschützt** sein soll. Öffentlich bedeutet, dass die Datei über ihre Adresse abrufbar sein kann.
3. Starten Sie die Vorbereitung. Das Studio zeigt danach Angaben für die Übertragung der Datei an.
4. Übertragen Sie die Datei mit dem vorgesehenen Verfahren und ergänzen Sie anschließend ihre Angaben in der Detailansicht.

**Wichtig:** Die Vorbereitung allein lädt noch keine Datei hoch. Die angezeigte Upload-Adresse ist nur begrenzte Zeit gültig und sollte nicht weitergegeben werden. Wenn Sie nicht wissen, wie die Übertragung erfolgt, nutzen Sie den Upload in der Medienbibliothek oder fragen Sie Ihre Administration.
