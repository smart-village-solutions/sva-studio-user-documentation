# Nachricht vorbereiten und veröffentlichen

Mit einer Nachricht informieren Sie über ein aktuelles Thema. Sie können den Text zuerst als Entwurf speichern und später veröffentlichen.

## Voraussetzungen

Sie haben Zugriff auf Nachrichten und die benötigten Rechte zum Anlegen und Veröffentlichen. Für ein Bild benötigen Sie eine passende, nutzbare Datei in der Medienbibliothek oder das Recht zum Hochladen.

## So gehen Sie vor

1. Öffnen Sie unter **Datenverwaltung → Inhalte** die Nachrichten und suchen Sie nach einem vorhandenen Eintrag. Für eine neue Nachricht wählen Sie **Inhalt erstellen** und dann den Inhaltstyp Nachricht.
2. Schreiben Sie eine verständliche Überschrift, eine kurze Einleitung und den Haupttext. Ergänzen Sie nur passende Kategorien, eine Quelle und Bilder.
3. Falls Sie ein Bild verwenden, wählen Sie es aus der Medienbibliothek oder laden Sie es im angebotenen Medien-Dialog hoch. Prüfen Sie Alternativtext und Nutzungsrechte.
4. Wählen Sie **Entwurf**, um ohne Veröffentlichung zwischenzuspeichern. Kontrollieren Sie den gespeicherten Eintrag und öffnen Sie ihn zum Überarbeiten wieder.
5. Wenn der Text fertig ist, wählen Sie **Sofort veröffentlichen** oder **Zeitgesteuert**. Prüfen Sie bei einer zeitgesteuerten Veröffentlichung Datum und Uhrzeit. Speichern Sie und beachten Sie die Rückmeldung.
6. Öffnen Sie die Nachricht erneut und prüfen Sie Status, Text und Bilder. Bei einer geplanten Nachricht kontrollieren Sie den angezeigten Veröffentlichungstermin.

**Ergebnis:** Die Nachricht steht als Entwurf bereit, ist veröffentlicht oder für den gewählten Zeitpunkt geplant.

## Wenn etwas nicht klappt

- Fehlt eine Veröffentlichungsaktion, prüfen Sie Ihre Rechte mit der Administration.
- Eine Push-Benachrichtigung ist eine zusätzliche, möglicherweise angebotene Aktion. Prüfen Sie Zielgruppe und Text besonders sorgfältig: Für eine Nachricht lässt sich ein Push nur einmal senden. Ein eingeschränkter Push schränkt die Sichtbarkeit der veröffentlichten Nachricht nicht ein.
- Meldet das Studio einen Medienfehler, prüfen Sie die Bildverknüpfung. Der Nachrichtentext kann bereits gespeichert sein.
