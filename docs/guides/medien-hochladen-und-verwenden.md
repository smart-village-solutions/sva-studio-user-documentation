# Medien hochladen und verwenden

Diese Anleitung führt vom Hochladen eines Bildes bis zu seiner Verwendung in einem Inhalt.

## Voraussetzungen

Sie haben Zugriff auf die Medienbibliothek und die nötigen Rechte zum Hochladen und Bearbeiten. Für die Verwendung in einem Inhalt benötigen Sie außerdem Zugriff auf dessen Formular. Klären Sie vor dem Upload, ob Sie die Datei veröffentlichen dürfen und welche Urheber- oder Lizenzangaben nötig sind.

## So gehen Sie vor

1. Öffnen Sie **Medien** und suchen Sie zuerst nach der Datei. So vermeiden Sie doppelte Uploads.
2. Wählen Sie eine Datei aus oder ziehen Sie sie in den Upload-Bereich der Medienbibliothek. Beobachten Sie Fortschritt und Rückmeldung. Prüfen Sie bei Bildern, ob das Dateiformat unterstützt wird.
3. Öffnen Sie die Datei und prüfen Sie Vorschau und Verarbeitungsstatus. Ergänzen Sie einen verständlichen Titel, bei Bildern einen Alternativtext sowie vorhandene Urheber- und Lizenzangaben.
4. Prüfen Sie die Sichtbarkeit: Eine öffentliche Datei kann über ihre Adresse abrufbar sein. Für Bilder in öffentlich sichtbaren Inhalten muss eine nutzbare öffentliche Adresse verfügbar sein.
5. Öffnen Sie den gewünschten Inhalt, etwa eine Nachricht oder Veranstaltung. Fügen Sie das Bild über die dort angebotene Medienauswahl hinzu und speichern Sie den Inhalt.
6. Prüfen Sie das Bild im Inhalt und anschließend beim Medium im Bereich **Nutzungstransparenz**, ob die Verknüpfung angezeigt wird.

**Ergebnis:** Die Datei ist in der Medienbibliothek erfasst und im gewählten Inhalt verknüpft.

## Wenn etwas nicht klappt

- Ein Upload kann noch verarbeitet werden. Prüfen Sie den Status, bevor Sie die Datei erneut hochladen.
- Wenn das Bild nicht verwendet werden kann, prüfen Sie Format, öffentliche Adresse und Rechte. Nicht jede Datei eignet sich für jeden Inhalt.
- Entfernen Sie eine Verknüpfung im betroffenen Inhalt. Eine bestehende Verwendung kann das Ändern oder Löschen des Mediums einschränken.
- Die eigene Seite **Datei vorbereiten** bereitet eine technische Übertragung vor; für die normale Dateiauswahl nutzen Sie die Medienbibliothek.
