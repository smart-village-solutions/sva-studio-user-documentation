# Rechtstexte versionieren und freigeben

Diese Anleitung richtet sich an Personen, die Rechtstexte im Studio verwalten dürfen. Lassen Sie Inhalt, Sprache, Zielgruppe und Freigabe vorab fachlich und rechtlich prüfen. Ein Rechtstext kann Personen im Studio zur Bestätigung angezeigt werden.

## Bestehende Fassungen prüfen

1. Öffnen Sie [Rechtstexte verwalten](/pages/admin.legal-texts.list). Suchen Sie nach dem Namen und filtern Sie bei Bedarf nach **Entwurf**, **Gültig** oder **Archiviert**.
2. Vergleichen Sie insbesondere **Version**, **Sprache**, **Status**, Zielgruppe und dokumentierte Akzeptanzen. Gleicher Name bedeutet nicht gleicher Inhalt.
3. Öffnen Sie die bisherige Fassung. Lesen Sie den vollständigen Text, bevor Sie eine neue Version vorbereiten.

## Neue Fassung vorbereiten

1. Wählen Sie **Rechtstext anlegen** und geben Sie Name, eine neue Versionsbezeichnung und Sprache ein. Verwenden Sie zunächst **Entwurf**.
2. Erfassen Sie den freigegebenen Inhalt im Editor und prüfen Sie die Darstellung.
3. Tragen Sie **Zielrollen-IDs** oder **Zielgruppen-IDs** nur ein, wenn der Text auf bestimmte Personen begrenzt werden soll. Die Felder erwarten durch Kommas getrennte IDs. Sind beide Felder leer, gilt der Text für alle Studio-Nutzer. Lassen Sie sich die richtigen IDs bei Bedarf von Ihrer Administration nennen.
4. Wählen Sie **Anlegen**. Prüfen Sie auf der anschließenden Detailseite Name, Version, Sprache, Inhalt und Zielgruppe erneut.

Eine bereits vorhandene Kombination aus Text, Version und Sprache kann nicht ein zweites Mal angelegt werden. Prüfen Sie bei einer Konfliktmeldung die bestehende Fassung. Die [Seitenhilfe zum Anlegen](/pages/admin.legal-texts.create) beschreibt die Eingabefelder.

## Fassung freigeben

1. Öffnen Sie die vorbereitete Fassung über [Rechtstexte verwalten](/pages/admin.legal-texts.list).
2. Wählen Sie **Gültig** und tragen Sie **Veröffentlicht am** ein. Dieses Feld ist für den Status **Gültig** erforderlich.
3. Speichern Sie und prüfen Sie Status, Text und Zielgruppe in der Liste.

**Wichtig:** Der Status **Gültig** macht den Text im aktuellen Studio für passende Personen relevant. Ein zukünftiger Wert in **Veröffentlicht am** ist keine verlässliche Zeitplanung für die Freigabe. Setzen Sie den Status erst dann auf **Gültig**, wenn die Fassung tatsächlich gelten soll.

Ändern Sie eine bereits gültige Fassung nicht beiläufig: Frühere Bestätigungen beziehen sich auf deren Inhalt. Stimmen Sie bei inhaltlichen Änderungen eine neue Version ab. Soll eine Fassung nicht mehr gelten, prüfen Sie **Archiviert**. Beim Löschen fordert das Studio eine Bestätigung; dokumentierte Akzeptanzen bleiben bestehen. Weitere Hinweise stehen in der [Seitenhilfe zum Bearbeiten](/pages/admin.legal-texts.detail) und im [Konzept zu Rechtstexten](/concepts/rechtstexte-und-versionen).
