# Eine Anfrage zu den eigenen Kontodaten stellen

Unter **Datenschutz & Transparenz** können Sie selbst eine Anfrage zu Ihren Kontodaten stellen und ihren Bearbeitungsstand verfolgen. Dazu benötigen Sie keine Rechte zur Benutzerverwaltung. Die Seite erreichen Sie über das Kontomenü.

## Passende Anfrage wählen

Öffnen Sie [Datenschutz & Transparenz](/pages/account.privacy) und wählen Sie die Aktion, die zu Ihrem Anliegen passt:

| Anliegen | Aktion im Studio |
| --- | --- |
| Erfahren, welche Kontodaten verarbeitet werden | **Auskunft anfordern** |
| Eine Datei mit eigenen Daten erhalten | **Datenexport anfordern** |
| Eine andere Berechtigung beantragen | **Rechteänderung beantragen** |
| Der Verarbeitung widersprechen | **Widerspruch einreichen** |
| Die Löschung eigener Daten beantragen | **Löschanfrage anfordern** |
| Die Verarbeitung einschränken lassen | **Einschränkung der Verarbeitung anfordern** |

Eine Anfrage ändert Rechte oder Daten nicht sofort. Sie stößt einen Vorgang an, der je nach Art geprüft werden muss.

## Anfrage absenden

1. Wählen Sie die passende Aktion und lesen Sie den Hinweis im geöffneten Fenster.
2. Ergänzen Sie bei Bedarf eine kurze Erläuterung. Bei **Rechteänderung beantragen** ist eine Begründung erforderlich: Beschreiben Sie, welche Aufgabe Sie übernehmen sollen und welcher Zugriff dafür fehlt.
3. Wählen Sie bei einem Datenexport das angebotene Dateiformat. Senden Sie die Anfrage ab.
4. Prüfen Sie die Bestätigung auf der Seite. Wenn ein Fehler erscheint, lesen Sie die Meldung und versuchen Sie es gegebenenfalls erneut.

## Stand und Ergebnis prüfen

1. Suchen Sie Ihren Vorgang in **Datenschutzvorgänge**. Suche sowie Filter nach Typ und Status helfen bei einer längeren Liste.
2. Öffnen Sie **Details**. Dort stehen Art, Status, Zeitpunkte und die Fall-ID. Bei einem blockierten oder fehlgeschlagenen Vorgang lesen Sie den angezeigten Grund.
3. Ein abgeschlossener Export kann über **Download** bereitstehen. Die Aktion erscheint nur, wenn ein Ergebnis verfügbar ist. Bewahren Sie die Datei geschützt auf, da sie persönliche Daten enthalten kann.

Wenn Sie Unterstützung benötigen, nennen Sie die Fall-ID, aber versenden Sie heruntergeladene Daten nur an berechtigte Personen. Die [Detailseitenhilfe](/pages/account.privacy-detail) erklärt die Anzeige des einzelnen Vorgangs.
