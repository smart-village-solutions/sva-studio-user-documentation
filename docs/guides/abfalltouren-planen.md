# Abfalltouren planen und veröffentlichen

Eine Tour verbindet Abfallarten, Abholorte und Termine. Wenn Sie im Abfallkalender Touren bearbeiten dürfen, prüfen Sie diese Angaben zusammen, bevor Sie Termine veröffentlichen.

## Eine Tour vorbereiten

1. Öffnen Sie **Abfallkalender → Touren**. Suchen Sie die Tour nach Namen, Status oder Gültigkeitszeitraum. Für eine neue Tour wählen Sie **Tour anlegen**.
2. Geben Sie einen verständlichen Namen ein und ordnen Sie die passenden Abfallarten und Abholorte zu.
3. Wählen Sie die Terminart: einzelne Termine oder einen wiederkehrenden Turnus. Bei einem Turnus prüfen Sie **Gültig ab** und gegebenenfalls **Gültig bis**. Diese Daten bestimmen, in welchem Zeitraum wiederkehrende Termine entstehen.
4. Prüfen Sie die berechneten Termine im Jahreskalender sowie bekannte Verschiebungen und Ausnahmen. Kontrollieren Sie auch einen betroffenen Abholort.
5. Speichern Sie die Tour. Neue und duplizierte Touren sind zunächst **Entwurf**. Erst mit **Veröffentlicht** werden ihre Termine für öffentliche und operative Ausgaben verwendet. Archivierte Touren bleiben im Studio sichtbar und bearbeitbar.

## Mehrere Touren ändern

Filtern Sie die Tourenliste und wählen Sie die gewünschten Einträge aus. **Alle gefilterten Touren auswählen** kann auch Treffer auf weiteren Ergebnisseiten umfassen. Prüfen Sie die angezeigte Zahl und mögliche ausgewählte Touren außerhalb des aktuellen Filters, bevor Sie **Status ändern** oder **Gültigkeitszeitraum ändern** öffnen.

Ein gemeinsamer Gültigkeitszeitraum ist nur für Touren mit wiederkehrendem Turnus gedacht. Individuelle und bedarfsabhängige Touren müssen Sie aus dieser Auswahl entfernen. Zeigt der Dialog einen Datumsfehler, korrigieren Sie die betroffenen Touren; eine Änderung mit ungültigem Zeitraum wird nicht gespeichert.

## Touren ins Folgejahr übernehmen

Wählen Sie **Tourensatz ins Folgejahr übernehmen**, legen Sie das Quelljahr fest und öffnen Sie die Vorschau. Das Studio zeigt, welche Touren übernommen werden können, bereits im Folgejahr gelten oder zunächst eine Prüfung benötigen. Lesen Sie Hinweise zu möglichen Konflikten und Ersatzdaten, wählen Sie die gewünschten Touren und bestätigen Sie erst nach der Zusammenfassung.

Die übernommenen Touren entstehen als **Entwurf**. Öffnen Sie anschließend die Touren des Folgejahres, kontrollieren Sie Termine, Abfallarten und Abholorte und veröffentlichen Sie nur fachlich freigegebene Touren.
