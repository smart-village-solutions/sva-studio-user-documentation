# Veranstaltung mit Ort anlegen

Mit dieser Anleitung erfassen Sie einen Termin und geben an, wo er stattfindet.

## Voraussetzungen

Sie haben Zugriff auf Veranstaltungen und das Recht, eine Veranstaltung anzulegen. Halten Sie Titel, Beschreibung, Anfang und Ende sowie die Angaben zum Ort bereit. Für eine Verknüpfung mit einem vorhandenen Ort muss dieser bereits erfasst und für Sie auswählbar sein.

## So gehen Sie vor

1. Öffnen Sie **Inhalte verwalten**, suchen Sie nach dem Termin und wählen Sie bei Bedarf **Neu → Veranstaltung**.
2. Geben Sie Titel und Beschreibung ein. Ergänzen Sie passende Kategorien, wenn sie angeboten werden.
3. Erfassen Sie Datum und Uhrzeit. Prüfen Sie bei einer mehrtägigen Veranstaltung Anfang und Ende; bei einer Wiederholung zusätzlich Intervall und Wochentage.
4. Geben Sie Veranstaltungsort und Adresse an. Wenn ein passender bereits erfasster Ort angeboten wird, können Sie ihn als **POI** verknüpfen. Ein POI ist ein Eintrag für einen Ort. Kontrollieren Sie die übernommenen Angaben.
5. Ergänzen Sie bei Bedarf Kontakt, einen Link, Preis, Hinweise zur Barrierefreiheit und Bilder. Verwenden Sie für Weblinks eine `https://`-Adresse.
6. Prüfen Sie die Sichtbarkeit, speichern Sie und lesen Sie die Rückmeldung. Öffnen Sie die Veranstaltung erneut, um Termin, Ort und Darstellung zu kontrollieren.

**Ergebnis:** Die Veranstaltung ist im gewählten Status gespeichert und enthält die geprüften Termin- und Ortsangaben.

## Wenn etwas nicht klappt

- Fehlt ein Ort in der Auswahl, prüfen Sie die Ortsangaben oder fragen Sie, ob er zuerst angelegt werden muss. Sie können die [Hilfe zum Anlegen eines Ortes](/pages/poi.content.create) nutzen.
- Karten- und Koordinatenfunktionen können fehlen. Ist eine Umwandlung verfügbar, kontrollieren Sie deren Ergebnis selbst.
- Bei einem Fehler zu Bildern kann die Veranstaltung bereits gespeichert sein. Prüfen Sie den Eintrag und seine Bildverknüpfungen vor einem erneuten Versuch.
