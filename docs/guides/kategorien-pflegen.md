# Kategorien pflegen

Kategorien helfen dabei, Inhalte zu ordnen. Eine Kategorie wie „Freizeit“ kann zum Beispiel die Unterkategorie „Sport“ enthalten. Diese Anleitung erklärt, wie Sie eine Kategorie anlegen, ändern und ihre Verwendung vor dem Löschen prüfen.

## Voraussetzungen

Sie sehen **Kategorien** im Studio und haben die nötigen Rechte für Ihre Aufgabe. Wenn eine Schaltfläche deaktiviert ist, wenden Sie sich an Ihre Administration.

## Kategorie anlegen oder ändern

1. Öffnen Sie **Kategorien**. Suchen Sie zuerst nach einer passenden vorhandenen Kategorie.
2. Wählen Sie **Kategorie anlegen**. Für eine Unterkategorie können Sie bei der gewünschten übergeordneten Kategorie die Aktion **Neue Unterkategorie** wählen.
3. Geben Sie einen eindeutigen Namen ein. Prüfen Sie die übergeordnete Kategorie und die **Position**, falls Sie eine Reihenfolge festlegen möchten.
4. Wählen Sie die passenden **Datentypen**, wenn die Kategorie nur für bestimmte Arten von Inhalten gedacht ist. Ergänzen Sie weitere Angaben nur, wenn sie für Ihre Arbeit benötigt werden.
5. Prüfen Sie **Aktiv** und speichern Sie. Kontrollieren Sie anschließend Name, Hierarchie und Status in der Liste.

Zum Ändern wählen Sie bei der Kategorie **Bearbeiten**. Wenn Sie den Aktivstatus einer Kategorie mit Unterkategorien ändern, kann eine Bestätigung erscheinen. Lesen Sie die Anzahl der betroffenen Unterkategorien, bevor Sie zustimmen.

## Vor dem Löschen prüfen

Wählen Sie **Löschen** nur, wenn die Kategorie nicht mehr benötigt wird. Das Studio bittet zuerst um Bestätigung. Bestehen noch Verwendungen, wird die Kategorie nicht gelöscht. Der Dialog zeigt dann zum Beispiel Unterkategorien oder Inhaltszuordnungen mit ihrer Anzahl. Prüfen Sie, wo die Kategorie noch eingesetzt wird, und klären Sie die Zuordnungen, bevor Sie erneut löschen.
