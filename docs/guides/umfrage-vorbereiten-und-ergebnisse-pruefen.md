# Umfrage vorbereiten und Ergebnisse prüfen

Mit einer Umfrage holen Sie Rückmeldungen zu einem klaren Thema ein. Wenn das Umfragemodul für Sie freigeschaltet ist, können Sie Fragen vorbereiten und später zusammengefasste Ergebnisse ansehen. Welche Aktionen verfügbar sind, hängt von Ihren Rechten ab.

## Vor dem Anlegen entscheiden

1. Formulieren Sie ein konkretes Ziel und einen verständlichen Titel. Erklären Sie in der Beschreibung, wofür die Antworten verwendet werden.
2. Legen Sie Start, Ende und gegebenenfalls das Zielgebiet fest. Ohne Enddatum ist die Umfrage zeitlich nicht begrenzt.
3. Entscheiden Sie, ob die Teilnahme anonym sein soll und wann Ergebnisse sichtbar werden dürfen. Stimmen Sie Datenschutz- und Transparenzhinweise mit der zuständigen Stelle ab.
4. Wählen Sie je Frage die passende Antwortart: eine Antwort, mehrere Antworten oder Freitext. Markieren Sie eine Frage nur dann als Pflichtfrage, wenn die Antwort wirklich benötigt wird. Fragen Sie keine unnötigen persönlichen Daten ab.

## Umfrage prüfen

Öffnen Sie **Umfragen** in der **Datenverwaltung** oder wählen Sie unter **Inhalt erstellen** den Typ **Umfrage**. Prüfen Sie nach dem Speichern Titel, Zeitraum, Beschreibung und die Reihenfolge der Fragen. Lesen Sie alle Antwortmöglichkeiten so, wie sie Teilnehmende sehen würden. Kontrollieren Sie den Status, bevor die Umfrage öffentlich werden soll.

Bei einer vorhandenen Umfrage finden Sie unter **Ergebnisse** Teilnahmezahlen und zusammengefasste Antworten, sofern bereits Daten vorliegen. Unter **Moderation** können berechtigte Personen Freitextantworten lesen. Einzelne Antworten lassen sich dort derzeit nicht freigeben, ausblenden oder löschen. Ein Export ist im aktuellen Umfrage-Editor nicht verfügbar.
