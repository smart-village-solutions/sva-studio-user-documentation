# Häufige Fragen

## Wo finde ich Hilfe zu meiner Aufgabe?

Im Studio öffnen Sie mit dem Fragezeichen neben dem Seitentitel die Erläuterungen zur
gerade geöffneten Seite. Weitere Hilfsangebote erreichen Sie über **Hilfe** in der
Studio-Seitenleiste. Auf dieser Website finden Sie die Erklärungen unter
[Seitenhilfe](/pages/). Die [Anleitungen](/guides/) führen durch Aufgaben auf mehreren
Seiten; Begriffe und Zusammenhänge stehen unter [Konzepte](/concepts/).

## Warum sehe ich eine Aktion nicht?

Sichtbare Fachbereiche hängen von den freigeschalteten Modulen ab. Die erlaubten
Aktionen hängen außerdem von Ihren Berechtigungen und gegebenenfalls Ihrer
Organisationszuordnung ab. Lesen Sie [Module und Berechtigungen](/concepts/module-und-berechtigungen)
oder wenden Sie sich an Ihre Administration.

## Wo kann ich mich mit anderen austauschen?

Der [SVA-Community-Bereich](https://verwaltungen-havelland.humhub.smart-village.app/s/sva-community/)
ist der Einstieg für den Austausch. Wenn Sie dort noch nicht angemeldet sind, führt der
Link zunächst zur Anmeldung.

## Wie kann ich die Dokumentation verbessern?

Wenn eine Erklärung fehlt, unverständlich oder veraltet ist, können Sie im
[GitHub-Repository der Dokumentation](https://github.com/smart-village-solutions/sva-studio-user-documentation)
ein [Issue erstellen](https://github.com/smart-village-solutions/sva-studio-user-documentation/issues/new).
Nennen Sie die betroffene Seite und beschreiben Sie, was Sie im Studio sehen oder welche
Information Sie vermissen. Wenn Sie den Text selbst ändern möchten, können Sie die
entsprechende Markdown-Datei im Repository bearbeiten und die Änderung als Pull Request
vorschlagen. Dafür benötigen Sie ein GitHub-Konto. Ohne GitHub-Zugang können Sie Ihren
Hinweis über die Support-Kanäle des von Ihrer Organisation beauftragten Dienstleisters
weitergeben.

## Wo melde ich weitere Fragen oder Probleme?

Fragen zu einer Erklärung oder Fehler in der Dokumentation können Sie als
[Issue im Dokumentations-Repository](https://github.com/smart-village-solutions/sva-studio-user-documentation/issues/new)
melden. Bei Fragen zur Bedienung, fehlenden Rechten oder einer Störung im Studio nutzen
Sie die Support-Kanäle des von Ihrer Organisation beauftragten Dienstleisters. Wenn Sie
diese nicht kennen, fragen Sie Ihre interne Studio-Administration nach dem richtigen
Kontakt. Allgemeine, nachvollziehbare Fehler im Studio können auch im
[Studio-Repository auf GitHub](https://github.com/smart-village-solutions/sva-studio/issues/new)
gemeldet werden. Veröffentlichen Sie in GitHub-Issues keine Zugangsdaten, personenbezogenen
Daten oder vertraulichen Inhalte.
